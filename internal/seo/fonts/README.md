# Liberation Sans

Unmodified `LiberationSans-Regular.ttf` from Liberation Fonts 2.1.5.

Source: https://github.com/liberationfonts/liberation-fonts/releases/tag/2.1.5

License: SIL Open Font License 1.1, included in `LICENSE`.

SHA-256: `76d04c18ea243f426b7de1f3ad208e927008f961dc5945e5aad352d0dfde8ee8`.

Used only for server-side SERP width estimates: regular 20 px titles and 14 px
descriptions, 96 DPI CSS pixels, no hinting. No runtime font download or OS font
dependency. The model does not reproduce Google snippet rewriting, bold query
matches, layout changes or complex-script shaping. Missing glyphs use a one-em
fallback and set the approximate flag.
