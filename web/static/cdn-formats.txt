Підтримувані експорти CDN

Спільні межі: незжатий UTF-8, 8 МіБ, 10 000 записів, рядок до 32 КіБ.
Обробляються GET/HEAD підтримуваних ботів. Власні/чужі IP не доводять справжність User-Agent.
Origin/cache без відповідного поля залишаються невідомими. HTTP 000 — відповідь відсутня, а не помилка HTTP.
Імпорти з перекриттям не підсумовуються. Однаковий request ID у файлі усувається;
якщо дані цього ID суперечливі, весь імпорт відхиляється. IP, request ID і сирий файл не зберігаються.

CloudFront standard TSV:
Потрібен рядок #Fields: з полями date time c-ip cs-method cs(Host) cs-uri-stem
sc-status cs(User-Agent) cs-uri-query cs-protocol. x-host-header має пріоритет над
cs(Host), який часто є доменом distribution. Додатково: x-edge-request-id,
x-edge-response-result-type або x-edge-result-type (результат edge, не origin).
Стандартний export не містить origin HTTP. Час UTC. Порядок полів задає #Fields:.

Cloudflare HTTP requests Logpush JSONL:
ClientIP, ClientRequestScheme, ClientRequestHost, ClientRequestURI,
ClientRequestMethod, ClientRequestUserAgent, EdgeResponseStatus, EdgeStartTimestamp.
Додатково: OriginResponseStatus (0 — невідомо), CacheCacheStatus, RayID.
EdgeStartTimestamp: RFC3339 або Unix nanoseconds, без довільного вгадування одиниць.

Vercel Drains proxy JSONL:
Об'єкт proxy: timestamp (Unix milliseconds/RFC3339), method, host, path,
userAgent (масив або рядок), clientIp, scheme, statusCode, vercelCache (опційно).
requestId на верхньому рівні опційний. Записи без proxy не є HTTP-подіями.
statusCode верхнього рівня не вважається статусом origin.

Fastly custom JSONL — необхідно налаштувати такий контракт:
{"timestamp":"2026-10-18T11:00:00Z","url":"https://example.com/page","method":"GET","client_ip":"203.0.113.2","user_agent":"OAI-SearchBot","status":403,"origin_status":200,"cache_status":"HIT","request_id":"example-request"}
origin_status, cache_status і request_id опційні. Час RFC3339.
Це не універсальний native-формат усіх Fastly endpoints.

Поля URL мають містити оригінальні query-параметри для точного HMAC-зіставлення.
Якщо експорт їх не містить, зіставлення URL з параметрами буде неповним.
У PostgreSQL значення query маскуються. Доступність журналів залежить від тарифу CDN.
