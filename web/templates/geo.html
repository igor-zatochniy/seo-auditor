Методика та межі достовірності
Джерело
Збережені успішні HTML-сторінки одного завершеного SEO-аудиту, до 1000 сторінок. Контентні сигнали беруться з початкового HTML, не з виконаного JavaScript. Опційні лабораторні LCP/CLS зберігаються окремо. Свіжість дорівнює даті сканування.
Зіставлення
IDF за сторінками вибраного аудиту, ваги title/H1/заголовків, дво- й трислівні фрази, обмежені українські та англійські словоформи. За відсутності точного збігу та словоформ допускається одна друкарська помилка для слів від 5 літер з однаковою першою літерою; числа не виправляються. Ціль потребує ≥50% термінів та ≥50% зваженого збігу. Релевантність не є SEO-рейтингом чи ймовірністю цитування. Синоніми й переклад не моделюються.
Контент
Пріоритет непорожнього main / role="main", далі article, інакше body. Виключаються nav, aside, form, dialog, footer, приховані та службові role-блоки. Header поза article виключається; заголовок, автор і дата у header статті зберігаються. CSS та JavaScript не виконуються.
Категорії
Структура відповіді, авторство та посилання, необов'язкова розмітка оцінюються окремо: виявлені / перевірені сигнали. Єдиного відсотка GEO немає. Schema не є спеціальною вимогою для AI-відповідей. Старі звіти зберігають попередню методику.
Пошукові боти
Дозволено правилами / заборонено / не перевірено стосується лише robots.txt та прочитаних директив. Це не підтверджує індексацію чи AI-цитування. OAI-SearchBot використовується для пошуку; блокування GPTBot для навчання не знижує оцінку ChatGPT Search.
Неповні дані
Старі аудити без сигналів контенту не отримують оцінки готовності. Невідоме не означає відсутнє. Невдалий збіг не доводить, що на сайті немає сторінки.
AI-цитування
Лише ручні спостереження з датою, системою та доказами. Нові перевірки доповнюють історію; таблиця й CSV показують останнє спостереження кожної системи. Це не автоматичний моніторинг.
Сутності бренду
Обмежена вибірка JSON-LD, Organization.name / sameAs, author / publisher та Product.brand. Посилання @id розв'язуються лише всередині сторінки. Назви порівнюються без урахування регістру, але юридичні суфікси та синоніми не вгадуються. Наявність sameAs не підтверджує власність або репутацію. Сигнали не змінюють оцінку GEO.
Спостережена видимість
Окремі імпорти GSC Web, GSC generative AI та зовнішніх AI-спостережень. Web-показники не є AI-показниками. Дані лише URL не приписуються окремим запитам, а відсутні кліки не замінюються нулем. Період, країна та пристрій задають область одного імпорту; імпорти не підсумовуються автоматично.
