    Методика та межі достовірності
    Кластери
    Local-topic-v1 використовує словоформи, IDF за запитами й complete-link: кожна пара повинна мати достатній збіг. В опційному словниковому режимі порівнюються також міжмовні поняття; це не універсальний переклад. Покрито: ≥80% термінів та зваженого збігу без ambiguity/limited; інші знайдені цілі часткові. Це не оцінка повноти відповіді.
    Джерело
    Усі збережені успішні HTML-сторінки домену одного завершеного SEO-аудиту, зокрема 10 000+, через пакетний PostgreSQL-індекс. Повнота корпусу та межі лексичних вибірок показуються окремо від повноти обходу сайту. Контентні сигнали беруться з початкового HTML, не з виконаного JavaScript. Опційні лабораторні LCP/CLS зберігаються окремо. Свіжість дорівнює даті сканування.
    Зіставлення
    IDF повного корпусу, ваги метаданих, фрази та обмежені словоформи й друкарські помилки. Опційний міжмовний шар використовує контрольований словник EN/UA/RU/PL/ES/RO, а не LLM чи універсальний перекладач. Початкова лексична ціль збережена. Незнайомі поняття не перекладаються; неоднозначні й обмежені результати не замінюють ціль. Релевантність не є SEO-рейтингом чи ймовірністю цитування.
    Контент
    Пріоритет непорожнього main / role="main", далі article, інакше body. Виключаються nav, aside, form, dialog, footer, приховані та службові role-блоки. Header поза article виключається; заголовок, автор і дата у header статті зберігаються. CSS та JavaScript не виконуються.
    Категорії
    Структура відповіді, авторство та посилання, необов'язкова розмітка оцінюються окремо: виявлені / перевірені сигнали. Єдиного відсотка GEO немає. Schema не є спеціальною вимогою для AI-відповідей. Старі звіти зберігають попередню методику.
    Пошукові боти
    Дозволено правилами / заборонено / не перевірено стосується лише robots.txt та прочитаних директив. Це не підтверджує індексацію чи AI-цитування. OAI-SearchBot використовується для пошуку; блокування GPTBot для навчання не знижує оцінку ChatGPT Search.
    Неповні дані
    Старі аудити без сигналів контенту не отримують оцінки готовності. Невідоме не означає відсутнє. Невдалий збіг не доводить, що на сайті немає сторінки.
    AI-цитування
    Лише ручні спостереження з датою, системою та доказами. Нові перевірки доповнюють історію; таблиця й CSV показують останнє спостереження кожної системи. Це не автоматичний моніторинг.
    Сутності бренду
    Обмежена вибірка JSON-LD, Organization.name / sameAs, author / publisher та Product.brand. Посилання @id розв'язуються лише всередині сторінки. Назви порівнюються без урахування регістру, але юридичні суфікси та синоніми не вгадуються. Наявність sameAs не підтверджує власність або репутацію. Сигнали не змінюють оцінку GEO.
    Спостережена видимість
    Окремі імпорти GSC Web, GSC generative AI та зовнішніх AI-спостережень. Web-показники не є AI-показниками. Дані лише URL не приписуються окремим запитам, а відсутні кліки не замінюються нулем. Період, країна та пристрій задають область одного імпорту; імпорти не підсумовуються автоматично.

    Історія ручних спостережень

    Імпорт спостережень

    UTF-8, до 2 МіБ та 5000 рядків. GSC Web: Query, Page, Impressions, Clicks, CTR, Position. GA4: Landing page, Session source, Sessions. Усі числа — без розділювачів тисяч.

    Кластер

    Нове порівняння

    Домен: відбір URL із sitemap за запитами й шляхами; вільний бюджет доповнюється обходом посилань до глибини 2. Конкретний URL: одна сторінка. Послідовне сканування з robots.txt і мережевим захистом. Для міжхостового редиректу вкажіть кінцевий URL. Query-параметри не допускаються.

    Порівняння сигналів

    Сутність бренду

    Збіги шукаються за повними нормалізованими словами. Правило контексту відокремлює неоднозначне слово від звичайного вживання. Підтверджені домени використовуються лише для класифікації джерел, не доводять зовнішню власність.

    Бажана політика AI

    Це намір власника для наступних планових запусків, а не SEO-оцінка. «Дозволити пошук» і «заборонити навчання» — незалежні налаштування.

    Google-Extended та Applebot-Extended — product tokens у robots.txt, а не окремі HTTP User-Agent. Боти для отримання сторінки за дією користувача не входять до цієї матриці. Зміни діятимуть для наступного SEO-запуску.

    Новий GEO-профіль

    Бажана політика AI

    Для іншого набору запитів створіть новий профіль. Бажана політика — намір власника, а не оцінка якості; незадані значення залишаються невідомими. Призупинення впливає лише на майбутні SEO-запуски.
